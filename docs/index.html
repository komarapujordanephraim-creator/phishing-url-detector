Using only features readable from the URL text, Gradient Boosting reaches 0.852 AUC, almost the same as all 16 features (0.856). URL length and path depth are the strongest signals.

Why the validation matters

The same website domain appears many times in this dataset. A normal random split puts the same domain in training and test, so a model can memorise domains and look far better than it is. Here the split and the 5-fold cross-validation are grouped by domain.

  1. Remove rows whose domain has both labels (3 domains).
  2. Split by domain, 75% train and 25% test.
  3. Compare Logistic Regression, Random Forest and Gradient Boosting, class-balanced.
  4. Report AUC, balanced accuracy, precision, recall, F1, an ablation and permutation importance.

Limits

  • The legitimate class has only 246 distinct domains. The test set has 70, so scores can move with a different split (cross-validation spread is about 0.05 AUC).
  • Some features came from live lookups (DNS, traffic rank, domain age) and may be stale.
  • This is a learning and portfolio project, not a production phishing filter.
